# NaSCon League — Android app

React Native + Expo (SDK 58, TypeScript). Built locally into `release/app-release.apk` (no Expo cloud services).

## Install
```bash
adb install -r mobile/release/app-release.apk   # Android 10 (API 29) or newer
```
The APK is signed with the Android debug keystore (fine for the judged demo).

## Point the app at the backend
- On the Login screen tap **Server: … (change)**, or open More → Settings.
- Emulator: `10.0.2.2:8080`. Phone: the laptop's IP on the team hotspot, e.g. `192.168.43.20:8080`.
- USB-connected Android phone: run `adb reverse tcp:8080 tcp:8080` on the laptop, then use `http://localhost:8080` in the app. Repeat the command after reconnecting USB. If `adb` is not on PATH, use `~/Android/Sdk/platform-tools/adb`.
- Tap **Save and test connection**; "Connected" means `/health` answered.

## Offline desk check (spec §8.4)
1. Online: open Fixtures, Standings and Club (each is saved in the phone's SQLite database).
2. Airplane mode: the banner at the top shows **Offline**; those screens still open from saved data.
3. As Organizer: Match → Enter score → tap a scoring button ("Saved offline"). As Manager: Club → Manage roster → player → Transfer/Loan/Release. Both show as **Pending sync** and in More → Sync status.
4. Force-close and reopen: the pending actions are still listed (stored in SQLite; the sign-in token is in the Android Keystore via expo-secure-store).
5. Network on: the app syncs automatically (or tap **Sync now**) and shows each result: Synced / Already synced / Not applied with a plain-language reason. The queue empties.

Switching user needs the server (login is online), so do the roster step signed in as the manager, or use two devices.

## Develop
```bash
cd mobile
npm install
npx tsc --noEmit      # typecheck
npx jest              # unit tests
npm run build:apk     # prebuild + gradlew assembleRelease -> release/app-release.apk (needs JDK 17 + Android SDK)
# Reuse an existing generated Android project:
SKIP_PREBUILD=1 npm run build:apk
```
`android/` is generated by `expo prebuild --clean`; never edit it by hand (it is gitignored).
